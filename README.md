# 오이오차 · 마음이 머무는 찻물

녹찻물 위에 마음을 띄우는 참여형 롤링페이퍼. Node.js 내장 HTTP 서버와 SQLite를 사용하며 별도 패키지 설치가 필요하지 않습니다.

## 실행

Node.js 22.13 이상(검증: 24.19)에서 저장소 디렉터리의 `npm start`를 실행합니다. 기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. 개발 중에는 `npm run dev`, API 검증은 `npm test`를 사용합니다.

## 기능

- 받는 사람과 제목을 입력하여 `/garden/<UUID>` 고유 페이지 생성
- 링크 복사, 이름·200자 메시지 작성, 잎·하트·별·네잎클로버·토끼 선택
- 포인터/터치 드래그로 배치, 키보드 방향키로 이동, 클릭으로 전문 보기
- 서버 SQLite 저장 및 3초 간격 동기화, 반응형 화면, 모션 감소 설정 지원

## 데이터와 배포

기본 데이터베이스는 `data/pond.sqlite`입니다. 재시작해도 유지됩니다. `DB_PATH`로 영구 디스크의 경로를 지정할 수 있습니다(상위 디렉터리는 미리 준비). 공개 HTTPS 주소에 Node 서버를 배포하면 같은 링크에서 여러 기기가 공통 DB를 사용합니다. 정적 파일만 배포하는 호스팅은 지원하지 않습니다. 호스팅에서 `data/` 또는 별도 DB 경로에 영구 볼륨을 연결하고, WAL 파일을 고려해 SQLite 백업 도구로 백업하세요. 서버 프로세스는 한 인스턴스로 운용하세요.

현재 공유 모델은 링크를 아는 사람 누구나 읽기·작성·배치 이동이 가능한 공개 협업 방식입니다. 대규모 공개 운영에는 인증/관리자 삭제/요청 제한을 별도로 추가해야 합니다. 공개 배포 및 도메인 연결은 아직 수행하지 않았습니다.

## 디자인 소재

첨부 ZIP은 완성 화면 JPG 3장으로, 분리된 배경/잎 원본이 아닙니다. `public/assets/oiocha_codex_*.jpg`에 보존했습니다. 실제 배경 `tea-water.png`는 첨부 시안에서 UI를 제거하도록 이미지 생성 도구로 재구성했습니다. 5종 잎은 자체 SVG로 그려 텍스트를 겹쳤습니다. 레이아웃은 독립적으로 구성했습니다. 원본 소재가 있으면 교체할 수 있습니다. Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시합니다.

## 파일 미리보기

루트의 `index.html`은 CSS·배경 이미지·스크립트를 모두 포함한 독립 미리보기입니다. `node build-preview.js`로 다시 생성합니다. 외부 리소스가 차단된 환경에서도 디자인과 메시지 작성을 확인할 수 있습니다. 이 파일은 브라우저 로컬 저장만 사용하며 여러 기기 공유는 지원하지 않습니다. 실제 SQLite와 공유 기능은 `npm start`로 실행하는 앱을 사용하세요.
