# 오이오차 · 마음이 머무는 찻물

녹찻물 위에 메시지를 띄우는 롤링페이퍼입니다. 기존 디자인을 유지하면서 GitHub Pages에서 Supabase로 개인별 찻잔과 메시지를 저장합니다.

## 온라인 저장 활성화

**먼저 [Supabase 설정 SQL](supabase/setup.sql)을 해당 프로젝트의 SQL Editor에서 실행한 뒤 배포하세요.** 기존 두 테이블이 있어도 재실행할 수 있고 데이터는 삭제하지 않습니다. 사용자가 대상 프로젝트에서 SQL 실행 성공을 확인한 뒤 `main`에 공개용 코드를 반영했습니다. 실제 공개 서비스의 교차 기기 저장 확인은 별도로 진행합니다.

공개 프로젝트 URL·Publishable key는 `public/cloud-storage.js`에 있습니다. Secret key, service_role, DB 비밀번호는 사용하지 않습니다. [설정·접근 권한·제한 상세](supabase/README.md)를 확인하세요.

## 실행·검증

Node.js 22.13 이상(검증: 24.19)에서:

```sh
npm ci
node build-preview.js
npm start
npm test
```

기본 포트는 3000입니다. `PORT`로 변경할 수 있으며 `npm run dev`로 개발합니다. 테스트 의존성만 추가했고 브라우저에서는 SDK 설치 없이 HTTPS API를 사용합니다.

- `public/` UI와 생성된 루트 `index.html` 모두 Supabase에 연결합니다.
- `#garden/<UUID>` 고유 URL로 찻잔을 생성·공유하고 다른 기기에서 복원합니다.
- 직접 새 찻잔을 생성했을 때만 해당 UUID를 이 브라우저에 기억합니다. 기본 주소는 마지막으로 만든 찻잔으로 복귀하고, 명시적인 친구 링크는 항상 그 친구 찻잔을 엽니다. 친구 방문이나 메시지 작성은 내 찻잔 기록을 바꾸지 않습니다.
- 이 기능 적용 전 만든 찻잔의 생성자는 소급해서 알 수 없습니다. 브라우저 데이터 삭제·시크릿 모드·다른 기기에서는 개인 링크가 필요합니다. 저장 차단 시에도 생성·공유 기능은 유지됩니다.
- 이름·200자 메시지·잎 모양·배치 좌표를 저장하고 3초마다 갱신합니다.
- 본문은 HTML로 실행하지 않고 텍스트로 표시합니다.
- 네트워크나 DB 설정이 실패하면 오류를 표시하며 로컬 저장으로 성공을 가장하지 않습니다.
- 예전 브라우저 데모의 localStorage는 삭제하지 않지만 자동으로 업로드하지는 않습니다.

기존 Node SQLite `/api`는 호환성과 회귀 검증을 위해 남겨뒀습니다. 새 브라우저 UI는 이 API 대신 Supabase를 사용합니다. 데이터 없는 무료 Node 서버 재시작에 의존하지 않습니다.

## 공유 범위와 제한

로그인 없이 참여하며 링크를 아는 사람은 해당 찻잔을 읽고 메시지를 남기며 잎 위치를 옮길 수 있습니다. 링크가 접근 권한이므로 비밀 메시지 용도로 사용하지 마세요. 전체 찻잔 목록 조회 및 직접 테이블 접근은 차단됩니다. 다른 찻잔 ID로 메시지를 이동할 수 없습니다.

입력 길이·종류·좌표 검증과 서버 측 기본 횟수 제한이 있습니다. 메시지 수는 고유 참여 인원 수가 아닙니다. 실제 대규모 캠페인·경품 운영에는 별도 소유자 인증과 CAPTCHA 등 추가 대응이 필요합니다.
