# NONGSHIM VINTAGE MACHINE

출생연도로 가까운 기준연도의 음료를 뽑고, 감열지 영수증에서 제품별 메시지를 확인하는 모바일 웹 데모입니다. 무광 레드·크림 자판기를 DOM/CSS로 구현했습니다. 참고 이미지를 화면 배경으로 사용하지 않으며 원본 제품 사진과 확정 메시지를 보존했습니다. 진열칸에는 작은 따뜻한 조명을 넣고, 원본 RGB를 그대로 유지하는 SVG 외곽 마스크로 사진 배경만 가립니다.

## 실행·빌드

Node.js 22 이상에서:

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

React + Vite + TypeScript입니다. `dist/`를 정적 호스팅에 배포합니다. Vite `base: './'`로 하위 경로도 지원합니다. DB·로그인·결제·분석·음향은 없으며 출생연도를 서버에 전송하거나 저장하지 않습니다.

## 동작

- 실제 첨부 제품 6개를 지정된 3×2 순서로 진열합니다.
- YYYY 네 자리, 1900~현재 연도 입력, Enter와 뽑기 버튼을 지원합니다.
- `idle → dispensing → printing → receipt_ready → receipt_open` 순서입니다.
- 음료가 배출구 내부의 가림막 뒤에서 약 1.25초 동안 천천히 내려와 착지한 후, 별도 슬롯에서 약 1.75초 동안 종이가 출력됩니다. 전체 약 3.1초입니다.
- 출력 중 중복 실행을 막고, 전문은 영수증을 탭해 모달을 열 때만 렌더링합니다.
- 출력구 위쪽 가운데의 확인 버튼 또는 인쇄된 종이를 탭해 확대할 수 있고, 닫기·Escape·다시 뽑기·PNG 저장을 지원합니다. PNG는 글꼴 준비 후 전체 문구의 길이로 높이를 계산합니다.
- 모션 감소 설정에서는 각 단계 0.12초, 회전·낙하·인쇄 모션 없이 진행합니다.
- 배출 중 리사이즈해도 비율 좌표와 배출구 내부 클리핑이 유지됩니다.

## 매칭·문구

`PRODUCT_DATA.json`이 데이터 원본이며, `src/matching.ts`에서 연도 거리로 매칭합니다. 동률은 **더 이른 기준연도**를 선택합니다. 같은 기준연도에서 승인된 후보가 여러 개면 무작위이며 테스트에서 난수 함수를 주입합니다.

도입 두 문장만 재계산하며 고정 본문·문단·구두점은 JSON 그대로입니다. 나이는 생일/출시월에 따른 만 나이가 아닌 **연도 차이**입니다.

| 출생연도 | 결과 기준연도·제품 |
|---|---|
| 1995 | 1995 웰치스, 같은 해 |
| 1998 | 1998 카프리썬, 같은 해 |
| 2005 | 2005 파워오투, 같은 해 |
| 2010 | 2010 오이오차 녹차, 같은 해 |
| 2014 | 2014 카프리썬 멀티비타민, 텍스트 결과 |
| 2000 | 1998 카프리썬, 2년 뒤 출생 |
| 2008 | 2010 오이오차, 두 살 차이 |
| 2003 | 2005 파워오투 |
| 1997 | 1998 카프리썬 |
| 2012 | 2010 오이오차, 동률 시 이른 연도 |

**웰치스 1995년은 캠페인 기획상 임시 기준연도입니다. 국내 웰치스 소다 최초 출시연도가 공식 검증되었다고 단정하지 않습니다.** 영수증도 '상품 기준연도'로 표시하고 지정된 '우리 곁에 찾아왔습니다' 문구를 씁니다.

## 이미지 검수 체크리스트

정식 대외 캠페인 공개 전 담당자 확인 항목:

- [ ] 첨부 제품 6종이 현행 판매 제품·용량·패키지와 일치하는지 확인
- [ ] 원본 사진 사용 권한과 브랜드 표기 검수
- [ ] 제공 사진의 흰 배경 및 카프리썬 사과의 체크무늬 배경 확인. PNG이지만 실제 투명 배경이 아닙니다. 현재 SVG 외곽 마스크로 배경만 가려 표시하며 원본 파일의 픽셀과 패키지 글자는 수정하지 않습니다. 공식 투명 제품컷이 확보되면 담당자 제공 파일로 교체 가능하며 AI 재생성/패키지 리터칭은 하지 않았습니다.
- [ ] **2014 공식 제품 사진 필수 보완**: 카프리썬 멀티비타민·오이오차 쟈스민티
- [ ] 오이오차 쟈스민티 별도 감성 문구 승인
- [ ] 웰치스 1995 캠페인 기준연도 사실관계 최종 검수

2014년은 승인된 공통 본문이 있는 **카프리썬 멀티비타민만 선택**하며 정확한 이름과 기준연도의 단순 이름표를 배출합니다. 가짜 패키지나 다른 맛 사진은 쓰지 않습니다. 쟈스민티 문구는 생성·복제하지 않습니다. 데이터의 `image` 경로가 보완되면 실제 사진 출력으로 자동 전환됩니다.

## 검증

`npm test`: 21개 매칭·유효성·동률·선후/동갑·확정 본문 테스트.

`node tests/browser.cjs`: Playwright + Chromium 설치 환경에서 개발 서버 실행 후 사용합니다. `CHROMIUM_PATH`, `DEMO_URL`로 경로를 바꿀 수 있습니다. 320/360/390/430/768/1440px에서 제품 로딩, 가로 넘침 없음, 두 출력구 분리, 입력/Enter, 모달, PNG 파일 높이, Escape, 재시도를 검증합니다. 일반 모션 순서·시간·전문 숨김과 2014 텍스트 결과도 확인합니다. 실제 iOS Safari 기기의 저장 동작은 별도 확인 대상입니다.

로컬 검증용 `artifacts/`는 배포하지 않습니다. 원본 사진과 빌드 결과는 SHA-256 바이트 동일성을 확인합니다.

## 기존 사이트와 분리한 배포

기존 GitHub Pages 저장소의 소스는 `projects/nongshim-vintage-machine/`, 공개 파일은 `nongshim-vintage/`에 추가합니다. 오이오차 루트와 웰치스 파일은 변경하지 않습니다. 소스 위치에서 `npm ci && npm run build` 후 `dist/` 내용을 공개 디렉터리에 복사해 업데이트합니다.
